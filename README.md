# ANALISIS CUSTOMER CHURN - TELCO DATASET
Proyek ini bertujuan untuk menganalisis faktor-faktor yang mempengaruhi pelanggan berhenti berlangganan (churn) dari layanan telekomunikasi, serta memberikan rekomendasi strategis untuk mengurangi churn.

# Dataset
- **Sumber Data**: Telco Customer oleh blastchar - Kaggle
- **Jumlah Data**: 7.043 baris dan 21 kolom
- **Fitur Penting**: Jenis Kontrak, biaya bulanan, tenure, layanan yang digunakan

# Tools & Library
- Python (Google Colab)
- Pandas, Numpy
- Matplotlib, Seaborn, Plotly
- Scikit-learn

# Proses Analisis
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Visualisasi Insight
4. Rekomendasi Bisnis
5. Model Prediksi Churn

# Insight Utama
- Pelanggan dengan kontrak bulanan memiliki tingkat churn tertinggi (>40%)
- Pelanggan yang churn cenderung memiliki tenure pendek
- Pelanggan yang churn memiliki biaya bulanan lebih tinggi
- Korelasi antar variabel numerik relatif lemah


# Rekomendasi

- Tawarkan kontrak jangka panjang untuk pelanggan bulanan
- Fokus retensi pada pelanggan baru (<6 bulan)
- Segmentasi pelanggan untuk personalisasi layanan
- Tinjau ulang struktur harga untuk pelanggan dengan tagihan tinggi


# Langkah Selanjutnya

- Membangun model prediksi churn (Logistic Regression, Decision Tree, dll)
- Integrasi ke dashboard (Power BI / Tableau)
- Evaluasi strategi melalui A/B Testing
